# 宾馆 PMS

一个面向单体宾馆/小型酒店的 PMS 系统原型，当前包含前台工作台、实时房态、预订、入住/退房、财务报表、交接班、操作审计和系统设置。

## 运行

```bash
npm start
```

默认地址：

```text
http://127.0.0.1:4174/
```

## 数据保存

后端提供 `GET /api/state` 和 `PUT /api/state`，前端会自动加载并保存 PMS 数据。

数据文件：

```text
data/pms-data.json
```

如果直接用静态文件方式打开页面，系统仍可作为前端原型运行，但数据不会持久化。

## 当前模块

- 前台工作台：预约到店、今日离店、实时房态
- 散客入住：身份信息、会员等级、渠道、押金、备注和入住天数/离店日期联动
- 在住与退房：账单余额、收款、退房
- 财务报表：日期查询、流水导出、打印
- 前台交班：值班人员交接记录
- 操作审计：关键操作留痕
- 系统设置：楼层、房间、员工、班次、打印机设置
